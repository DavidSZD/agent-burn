# Public Windows release checklist

This repository can be published as a public fork after a final maintainer review.

## Publish

1. Fork `Melvynx/agent-burn` on GitHub.
2. Push the source branch and create a GitHub Release.
3. Upload `apps/windows/target/release/bundle/nsis/Agent Burn_<version>_x64-setup.exe` to the release assets.
4. Share the release page or the direct `.exe` asset. Do not share files from `AppData`.

## Keep in the repository

- `apps/windows/src`, `apps/windows/ui`, `apps/windows/scripts`, and configuration files.
- `apps/windows/src/litellm-pricing-embedded.json` (required at compile time).
- Public brand icons and build scripts.

## Never commit

- `apps/windows/resources/agent-burn.exe` (local staged binary; generated by the build script).
- `apps/windows/target/`, `node_modules/`, logs, screenshots, AppData exports, API keys, tokens, or personal history files.
- Any unrelated personal assets copied into the working tree.

## Windows compatibility

The current installer is a per-user NSIS installer for Windows x64 (Intel/AMD), with a WebView2 bootstrapper when WebView2 is missing. It is suitable for normal Windows 10/11 x64 PCs. It is not a native 32-bit or ARM64 build; ARM64 Windows may run it through emulation, but that is not guaranteed.

Before publishing, run the Windows build and the Rust/Node test commands from the repository README, then inspect the release asset on a clean Windows machine.
